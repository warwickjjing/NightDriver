# NightDriver 작업 순서 문서 (Day1~2 안정화 + 분기 손님 1명)

이 문서는 현재 개발 단계에서 "무엇부터 해야 하는지"를 순서대로 정리한 실행용 체크리스트입니다.

## 0. 목표

- Day1~2 기본 루프를 안정화한다.
- 분기 손님 1명 프로토타입을 만든다.
- 승천 카운트(`ascensionCount`) 기반 조건 분기를 검증한다.

---

## 1단계: 데이터 규칙 고정 (가장 먼저)

이 단계가 흔들리면 이후 모든 작업이 다시 깨집니다.

- [ ] `ClientDefinition` 입력 규칙 확정
  - `clientId`
  - `prefab`
  - `vehiclePrefab` (없으면 `None`)
  - `spawnPointId`
  - `startNode`

- [ ] `ClientBehaviour.destinations[]` 입력 규칙 확정
  - `id` (Yarn `<<setDestination ...>>`와 완전 일치)
  - `location` (도착 판정 위치)
  - `exitPoint` (하차 후 보행 목표)
  - `arrivalYarnNode` (도착 후 대화 노드, 필요 없으면 빈값)

- [ ] 승천 규칙 확정
  - 성공 조건: 진짜 목적지 도착 + 처리 완료
  - 실패 조건: 표면 목적지로 종료
  - 증가 규칙: 성공 시 `ascensionCount +1`

- [ ] 7일차 조건 확정
  - 예시: `ascensionCount >= 4`

완료 기준:
- 필드 이름/의미가 팀 내에서 동일하게 이해됨
- 테스트용 손님 1명 데이터 입력이 가능한 상태

---

## 2단계: Day1 수직 슬라이스 완성 (공포 연출 제외)

시스템이 끝까지 한 번 도는지 먼저 확인합니다.

- [ ] Day1 손님 1명 배치
- [ ] 손님 + 차량 스폰 확인
- [ ] HUD가 손님 방향을 가리키는지 확인
- [ ] 손님 근접 시 HUD 숨김 + `말걸기[E]` 프롬프트 표시 확인
- [ ] 첫 대화 진행 확인 (`startNode`)
- [ ] `<<setDestination ...>>` 후 HUD 목적지 전환 확인
- [ ] 목적지 도착 시 `내리기[E]` 표시 확인
- [ ] 하차 후 손님 보행/소멸 확인
- [ ] 다음 콜로 넘어가는지 확인

완료 기준:
- 콘솔 에러 없이 콜 1개가 끝까지 진행됨

---

## 3단계: Day2 분위기 레이어 추가 (마지막 손님만)

시스템 위에 공포 연출을 얹되, 시스템을 건드리지 않습니다.

- [ ] Day2 Call1~3: 일반 톤 유지
- [ ] Day2 Call4: 지하주차장 연출 적용
  - [ ] 발소리 에코
  - [ ] 조명 깜빡임
  - [ ] 그림자 1회 노출

완료 기준:
- 연출이 들어가도 기본 루프(스폰/대화/목적지/하차)가 깨지지 않음

---

## 4단계: 분기 손님 1명 프로토타입

추천 케이스: "회사 빌딩 vs 병원" 분기.

- [ ] 표면 목적지 1개 설정
- [ ] 진짜 목적지 1개 설정
- [ ] Yarn 선택지 2개 구성
  - [ ] `<<setDestination Surface_X>>`
  - [ ] `<<setDestination True_Y>>`
- [ ] 표면 목적지 루트 종료 확인
- [ ] 진짜 목적지 루트 승천 처리 확인

완료 기준:
- 같은 손님에서 선택지에 따라 서로 다른 결과가 확실히 재현됨

---

## 5단계: 승천 카운트/조건 테스트

- [ ] 현재 `ascensionCount` 확인 방법 준비 (로그 또는 디버그 UI)
- [ ] 진짜 목적지 성공 시 +1 확인
- [ ] 표면 목적지 선택 시 증가 없음 확인
- [ ] 누적값 기반 조건(`>=4`) 테스트

완료 기준:
- 분기 결과가 수치로 남고, 조건문이 정상 작동함

---

## 6단계: 안정화 체크 (릴리즈 전 최소 기준)

- [ ] 게임 시작 직후 Day1 스폰 정상
- [ ] Day 전환 시 기존 손님/차량 정리 누락 없음
- [ ] HUD와 프롬프트 중복 노출 없음
- [ ] 대화 입력 충돌 없음
- [ ] 콘솔 에러 0

완료 기준:
- 2회 연속 플레이에서도 동일하게 재현됨
