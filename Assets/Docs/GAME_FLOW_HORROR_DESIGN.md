# NightDriver 공포 설계 아티팩트 (v1)

## 1. 코어 게임 루프

핸드폰 콜 수신  
-> 손님 위치 이동  
-> 손님과 대화 (목적지 선택/설득)  
-> 목적지 이동  
-> 도착 처리(내리기)  
-> 손님 하차 후 사라짐(또는 승천)  
-> 다음 콜

- 하루 4명 기준
- 7일차는 조건부 특수 콜(동생) 발생

---

## 2. 핵심 시스템 요약

### 2.1 목적지 분기 시스템

각 손님은 `표면 목적지`와 `진짜 목적지`가 있을 수 있다.

- 표면 목적지로 이동: 미련 해소 실패 (소멸/배회)
- 진짜 목적지로 설득 후 이동: 승천 처리
- 승천 횟수 누적이 엔딩 분기 트리거가 됨

### 2.2 승천 카운트

- 변수 예시: `ascensionCount`
- 7일차 조건 예시: `ascensionCount >= 4`일 때 동생 콜 배차

### 2.3 공포 연출 배치 축

- 픽업 이동 구간 (차에서 내려 걸어감)
- 픽업 현장 구간 (손님 조우)
- 드라이빙 구간 (차량 내부 공포)

---

## 3. 점프스케어 정책

- 총 2회
- 5일차 1회 (중반)
- 6일차 1회 (후반)
- 1~4일차는 분위기형 공포 중심
- 7일차는 정서적 클라이맥스 중심

---

## 4. 일차별 시나리오(요약)

### Day 1 — 평범 + 복선

- 톤: 일상에 미세한 이질감
- 공포 강도: ★☆☆☆☆
- 점프스케어: 없음

### Day 2 — 지하주차장(마지막 손님 1명만 강한 이질감)

- 톤: 현실 기반 불안감
- 공포 강도: ★★☆☆☆
- 점프스케어: 없음

### Day 3 — 노인(사라짐 계열)

- 톤: 잔향형 공포
- 공포 강도: ★★★☆☆
- 점프스케어: 없음

### Day 4 — 철거된 아파트(역방향 내비)

- 톤: 슬픔 + 소름
- 공포 강도: ★★★☆☆
- 점프스케어: 없음

### Day 5 — 터널 암전

- 톤: 시각 충격
- 공포 강도: ★★★★☆
- 점프스케어: 1회 (암전 후 조수석 실루엣)

### Day 6 — 사고 현장

- 톤: 청각 + 근접 충격
- 공포 강도: ★★★★★
- 점프스케어: 1회 ("저 언제 죽었어요?" 속삭임)

### Day 7 — 동생 지현 (조건부)

- 톤: 감정적 피크 / 진실 해소
- 공포 강도: ★★★★★
- 점프스케어: 없음(연출 선택 가능)

## 6. 7일차 조건/엔딩 분기

### 조건

- `ascensionCount >= 4`이면 동생 콜 활성화

### 엔딩 예시

- 엔딩 A (해방): 진짜 목적지로 인도 성공
- 엔딩 B (집착): 표면 목적지 고집/실패

---

## 7. 구현 체크리스트 (실무용)

- 손님별 표면/진짜 목적지 데이터 입력
- 손님별 단서 대사(최소 2개) 배치
- `setDestination` 분기 노드 연결
- 도착 프롬프트(`내리기[E]`) 확인
- 하차 후 이동/소멸 연출 확인
- 승천 카운트 증감 로직 확인
- Day7 조건 분기 및 테스트 케이스 작성
- 점프스케어 2회 타이밍 리허설(스트리머 반응 기준)

---

## 8. 연출 원칙

1. 점프스케어는 적고 강하게(2회)
2. 나머지는 분위기/서사 공포로 밀도 확보
3. 공포 + 감정(미련/해소)을 함께 설계
4. 플레이어의 선택이 결과를 바꾼다는 감각 유지
