# 🚗 심야 대리기사 — 최종 개발 플랜 (7일 구조)

---

## 📖 세계관 & 컨셉

2024년 서울. 자정이 넘으면 도시의 이면이 드러난다.  
미련을 품고 죽은 자들이 산 자의 틈에 섞여, 스스로 죽었다는 사실을 모른 채 마지막 기억의 루틴을 반복하고 있다.  
플레이어는 처음엔 이 사실을 전혀 모른 채 **평범한 대리운전 기사**로 게임을 시작한다.

> 🎯 목표 플레이타임: **1~2시간 (1회차 기준)**  
> 엔딩 3개 전부: 약 2시간 30분

---

## 👤 주인공

**박도현 (38세)** — 전직 형사.  
3년 전 미해결 사건으로 동생을 잃고 자진 사직.  
생계를 위해 대리운전을 시작하지만,  
무의식적으로 그날 밤 동생이 탔던 마지막 차의 행적을 쫓고 있다.

| 2일차 | 균열의 시작 | 손님 대화가 미묘하게 이상함. 목적지 도착 후 손님 사라짐. 뉴스 한 줄 | 15분 |

## 🎭 스토리 — 3막 구조

### 1막 "이상한 손님들" (1~2일차)

1일차는 완벽하게 평범하다. 요금 받고, 집에 간다.  
2일차, 손님이 내린 자리에 아무것도 없다.  
다음날 뉴스: *"강남구 일대 신원미상 유골 발견"*  
도현은 그냥 넘긴다.

> 핵심 감정: 일상감, 미묘한 불안

---

### 2막 "같은 밤을 사는 자들" (3~6일차)

3일차부터 목적지 선택지가 등장한다.  
유저는 대화 단서를 조합해 **진짜 목적지**를 스스로 추리해야 한다.

4일차, 도현의 독백:
> "(생각) ...설마 그 손님이? 아니야. 말이 안 돼."

하지만 말이 된다. 손님의 눈을 오래 바라보면  
**죽던 순간의 잔상**이 보이기 시작한다.

5~6일차, 손님들의 사연이 서로 연결되고 있음이 드러난다.  
그리고 모든 사연의 중심에 **하나의 미해결 사건**이 있다.

> 핵심 감정: 연민, 긴장, 죄책감

---

### 3막 "그날 밤" (7일차)

7일차 마지막 콜. 탑승한 손님은 **동생 박지현**이다.  
지현은 도현을 알아보지 못한다. 자신이 죽었다는 것도 모른다.  
대화를 통해 미해결 사건의 전모가 밝혀지고,  
도현은 선택해야 한다.

> 핵심 감정: 슬픔, 해방감, 카타르시스

---

## 🔀 엔딩 분기

3~6일차 **승천 성공 횟수**가 7일차 진입 조건을 결정한다.

```
3~6일차
  ├─ 승천 4회 이상 ──→ 7일차: 동생 박지현 탑승
  │                        ├─ 지현이 원하는 장소로 간다
  │                        │     └─ 🟢 엔딩 A "해방"
  │                        │          지현 승천. 도현, 처음으로 울음.
  │                        │          "잘 가, 지현아."
  │                        │
  │                        └─ 내 맘대로 다른 곳으로 간다
  │                              └─ 🔴 엔딩 B "집착"
  │                                   지현이 떠나지 못하고 갇힘.
  │                                   도현, 매일 밤 운전을 계속함.
  │                                   "오빠가 있잖아."
  │
  └─ 승천 4회 미달 ──→ 7일차: 동생 탑승 없음
                          평범한 마지막 콜로 끝남
                          └─ 🔵 엔딩 C "진실을 마주하지 못한 자"
                               도현은 끝내 진실을 외면했다.
                               손님들은 여전히 떠돌고 있다.
                               도현도 그들과 같아지고 있다는 암시.
```

### 엔딩 설계 포인트

| 엔딩 | 핵심 감정 | 조건 |
|------|----------|------|
| 🟢 A "해방" | 슬프지만 따뜻한 이별 | 승천 4회 이상 + 지현의 목적지 선택 |
| 🔴 B "집착" | 죄책감, 이기심 | 승천 4회 이상 + 임의 목적지 선택 |
| 🔵 C "진실을 마주하지 못한 자" | 공허함, 소름 | 승천 4회 미달 — 동생을 만나지도 못함 |

## 💬 대화 시스템

### 텍스트 연출 규칙

| 유형 | 연출 |
|------|------|
| 손님 대사 | 우측 말풍선, 흰색 |
| 도현 대사 | 좌측 말풍선, 흰색 |
| 도현 생각 | 이탤릭체, 흐린 파란색, 괄호 표시 |
| 시스템 힌트 | 화면 하단, 매우 흐리게 — **3일차 이후부터만 등장** |

### 대화 예시 (3일차)

```
[손님] xx빌딩으로 가주세요.
[도현] 네, 알겠습니다.
[손님] 사실 그곳이 제일 혐오스럽지만요..
[도현] 네?
[손님] 아무것도 아닙니다.

(도현 생각) 뭔가 다른 목적지가 있는 걸까..
(도현 생각) 손님이 많이 다쳐보이는데.. 병원에 안 가도 되는 걸까.

─────────────────────────
📍 목적지 선택
  🏢 xx빌딩으로
  🏥 병원으로
─────────────────────────
```

### 분기 결과

```
xx빌딩 선택 시
  └─ 손님: "감사합니다. 여기서 많은 걸 잃었거든요."
     → 사라짐. 다음날 뉴스: "xx빌딩 인근 유골 발견"
     → (도현 생각) "...아."

병원 선택 시 (A)
  └─ 손님: "고마워요. 사실 거기서 죽었거든요."
     → 눈물 흘리며 사라짐 (승천)

병원 선택 시 (B)
  └─ 손님: "여긴... 왜 여기로 왔어요?"
     → 창밖 응시, 하차 거부 → 공포 이벤트 트리거
```

## 🔁 1런(1일) 흐름

```
밤 시작
  └─ 콜 배정 (손님 1~3명 랜덤)
       └─ 픽업 → 대화 → 단서 수집
            └─ 목적지 판단 (유저 선택)
                 ├─ 정상 목적지  → 요금 수령 → 다음 콜
                 ├─ 진짜 목적지 → 손님 승천 → 보너스 획득
                 └─ 함정 목적지 → 공포 이벤트 발생
                                   ├─ 생존 → 다음 콜
                                   └─ 실패 → 당일 런 종료
밤 종료 → 정산 화면 (1~2일차: 단순 요금만)
         → 업그레이드 선택 (3일차부터 등장)
         → 다음 밤
```

## 😱 공포 이벤트 3종

### Type A — "돌변" (3일차 첫 등장)
```
트리거: 잘못된 목적지 입력
연출:
  1. 라디오 꺼짐
  2. 백미러 손님 얼굴 서서히 변형 (Shader Graph)
  3. 내비 오작동 → 수동으로 진짜 목적지 찾아야 함
  제한 시간 내 도달 → 성공 / 초과 → 당일 런 종료
```

### Type B — "사라진 도로" (5일차 첫 등장)
```
트리거: 손님을 180초 이상 태울 때
연출:
  1. 도로가 낯선 구조로 바뀜
  2. GPS 먹통 → 표지판 패턴으로 탈출구 찾기
  3. 같은 교차로가 반복되는 루프
  올바른 방향 3번 연속 선택 → 탈출
```

### Type C — "복수 소환" (6일차 첫 등장)
```
트리거: 2런 연속 같은 유형 실수
연출:
  1. 도로 위에 같은 손님이 여럿 서 있음
  2. 차를 멈추면 에워쌈
  3. 대화 단서로 진짜 손님 찾기 (3초 제한)
```

## 💰 보상 & 업그레이드 시스템

### 보상 화폐 3종

| 화폐 | 획득 방법 | 의도 |
|------|----------|------|
| 💵 현금 | 정상/진짜 목적지 도달 | 못해도 조금씩 쌓임 |
| 👻 영혼의 파편 | 손님 승천 성공 | 잘해야 많이 획득 |
| 🧩 기억 조각 | 단서 완벽 수집 | 스토리 탐구 보상 |

> ⚠️ **1~2일차**: 단순 요금 정산만 (대리운전 시뮬 유지)  
> **3일차부터**: 도현 독백과 함께 업그레이드 화면 자연 등장

### 업그레이드 트리

#### 🚗 차량 (현금)
```
부적 부착            → 공포 이벤트 발생 확률 -10%
  └─ 고급 부적       → 발생 확률 -25%
블랙박스 업그레이드  → 단서 1개 자동 수집
  └─ AI 블랙박스     → 목적지 힌트 제공
방향제               → 돌변 타이머 +30초
  └─ 특수 방향제     → 돌변 타이머 +60초
```

#### 👁️ 능력 (영혼의 파편)
```
잔상 감지            → 눈 마주침 없이 잔상 발동
  └─ 깊은 잔상       → 죽음의 장소까지 특정
직감                 → 틀린 목적지 보기 1개 제거
  └─ 예지            → 함정 목적지 미리 경고
공감                 → 손님 감정 게이지 표시
  └─ 교감            → 손님이 단서 1개 먼저 알려줌
```
